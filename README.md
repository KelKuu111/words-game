# :sparkles:------{ Игра в слова }------:sparkles:
#### :star: Если понравилась игра — поставь звёздочку:star:
## ------{ Правила:
Суть игры - называть слова, которые начинаются на последнюю букву предыдущего слова.
Игроки ходят по очереди. Побеждает тот, кто последним назвал слово.

## ------{ Рекомендации:
1. Для того, чтобы начать игру, распакуйте папку из архива в удобное для вас место
2. Убедитесь, что файл russian.txt находится в той же папке, что и игра
3. Для корректной работы требуется Python 3.13 или выше
4. При первом запуске файл words.json создастся автоматически

## -----{ Управление:
### В игре:
- Просто вводите слова и нажимайте Enter
- Команда "pass" - пропуск хода (3 пропуска и вы проиграли)
- Команда "exit" - выход в главное меню с сохранением прогресса

### В главном меню:
- "1" - продолжить игру
- "2" - начать новую игру
- "on/off" - включить/выключить проверку по словарю
- "exit" - выход из программы

## -----{ Файлы:
- words_game.py - основной файл игры
- russian.txt - словарь русских слов
- words.json - файл сохранения (создаётся автоматически)
- README.md - этот файл
